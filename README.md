# My Projects

This repository serves as a comprehensive portfolio of machine learning and artificial intelligence projects, experiments, and implementations across various domains.

## Repository Structure

The repository is organized into the following main sections:

### Academic Projects

More structured projects with complete codebases, documentation, and experiments:

-   **cnn-fashion-mnist-comparison**: Comparison of different CNN architectures on the Fashion MNIST dataset
-   **gradient_descent_project**: Implementation and comparison of various gradient descent optimization algorithms
-   **pytorch_introduction**: Introduction to PyTorch with examples covering basic tensor operations to more advanced usages

### Computer Vision

Notebooks exploring various computer vision techniques and models:

-   Dreambooth data augmentation pipeline
-   Florence-2 model inference
-   SDXL diffusion model experiments
-   Stable diffusion models comparison
-   Vision transformer classification

### Data Analysis

Notebooks focusing on data exploration and analysis:

-   Data analysis with Pandas AI
-   Wine dataset comprehensive analysis

### Deep Learning

Explorations into neural network architectures:

-   Multilayer perceptron experiments

### Large Language Models (LLM)

Projects related to large language models:

-   Chat with document implementation
-   RAG (Retrieval-Augmented Generation) evaluation

### Machine Learning

Implementation of classical machine learning algorithms:

-   Decision tree implementation
-   Naive Bayes implementation

### Natural Language Processing (NLP)

Text and language processing projects:

-   CATMAT items merging
-   Topic modeling with pyLDAvis

### Sequential Pattern Mining

Experiments with pattern discovery in sequential data:

-   Sequential pattern mining implementation
-   Synthetic dataset generation for pattern mining

## Getting Started

Each project or notebook typically has its own dependencies. For academic projects, check the `requirements.txt` file in the specific project folder.

For notebooks, the required libraries are typically imported at the beginning of each file.
