# Meus Projetos

[![en](https://img.shields.io/badge/lang-en-red.svg)](README.md)

Este repositório serve como um portfólio abrangente de projetos, experimentos e implementações de aprendizado de máquina e inteligência artificial em vários domínios.

## Estrutura do Repositório

O repositório está organizado nas seguintes seções principais:

### Academic Projects (Projetos Acadêmicos)

Projetos mais estruturados com bases de código completas, documentação e experimentos:

-   **cnn-fashion-mnist-comparison**: Comparação de diferentes arquiteturas CNN no conjunto de dados Fashion MNIST
-   **gradient_descent_project**: Implementação e comparação de vários algoritmos de otimização de gradiente descendente
-   **pytorch_introduction**: Introdução ao PyTorch com exemplos que cobrem desde operações básicas com tensores até usos mais avançados

### Computer Vision (Visão Computacional)

Notebooks explorando várias técnicas e modelos de visão computacional:

-   Pipeline de aumento de dados com Dreambooth
-   Inferência do modelo Florence-2
-   Experimentos com modelos de difusão SDXL
-   Comparação de modelos de difusão estáveis
-   Classificação com transformers para visão

### Data Analysis (Análise de Dados)

Notebooks focados na exploração e análise de dados:

-   Análise de dados com Pandas AI
-   Análise abrangente do conjunto de dados de vinhos

### Deep Learning (Aprendizado Profundo)

Explorações em arquiteturas de redes neurais:

-   Experimentos com perceptron multicamada

### Large Language Models (LLM) (Modelos de Linguagem Grande)

Projetos relacionados a modelos de linguagem grandes:

-   Implementação de chat com documento
-   Avaliação de RAG (Geração Aumentada por Recuperação)

### Machine Learning (Aprendizado de Máquina)

Implementação de algoritmos clássicos de aprendizado de máquina:

-   Implementação de árvore de decisão
-   Implementação de Naive Bayes

### Natural Language Processing (NLP) (Processamento de Linguagem Natural)

Projetos de processamento de texto e linguagem:

-   Mesclagem de itens CATMAT
-   Modelagem de tópicos com pyLDAvis

### Sequential Pattern Mining (Mineração de Padrões Sequenciais)

Experimentos com descoberta de padrões em dados sequenciais:

-   Implementação de mineração de padrões sequenciais
-   Geração de conjunto de dados sintéticos para mineração de padrões

## Começando

Cada projeto ou notebook geralmente tem suas próprias dependências. Para projetos acadêmicos, verifique o arquivo `requirements.txt` na pasta específica do projeto.

Para notebooks, as bibliotecas necessárias são tipicamente importadas no início de cada arquivo.
